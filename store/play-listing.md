# Google Play 掲載情報（まなびチーム）

Play Console の「ストアの掲載情報」にそのまま貼り付けて使う。文字数の上限に注意。

## 基本

| 項目 | 内容 |
|---|---|
| アプリ名（30文字まで） | まなびチーム |
| パッケージ名 | com.manabiteam.app |
| カテゴリ | 教育 |
| 料金 | 無料 |
| 広告 | なし |
| アプリ内課金 | なし |

## 簡単な説明（80文字まで）

```
ひとりでも家族でも。勉強の時間を計って記録し、毎日の習慣をつづけられる学習記録アプリ。
```

## 詳しい説明（4000文字まで）

```
「まなびチーム」は、勉強の時間を計って、毎日つづけるためのアプリです。
使い方は2つ。あなたに合うほうを選べます。

■ ひとりで使う
・ストップウォッチ：勉強をはじめてから終わるまでを計ります
・タイマー：10分・25分・45分など、時間を決めて集中できます
・がんばったことメモ：勉強のあとに一言残して、あとから見返せます
・毎日の目標と連続日数：1日の目標時間を決めて、達成した日の連続をカウントします
・科目は自由に追加・名前変更・色の変更ができます
・1週間の勉強時間をグラフで確認できます

■ 家族で使う
・保護者がこどもにタスク（宿題や課題）を出せます
・こどもは自分の画面でタイマーを使って勉強し、タスクを完了にできます
・保護者は、こどもごとの学習時間・連続日数・科目別の時間を見られます
・保護者の画面は、計算問題を解かないと開けません（こどもが間違って開かないため）

■ 安心して使えます
・アカウント登録しなくても、すべての機能が使えます
・会員登録（メールアドレス）をすると、機種変更しても記録を引き継げます
・登録しない場合、入力した内容はすべてあなたの端末の中だけに保存されます
・広告はありません

勉強の習慣づくりに、ぜひお使いください。
```

## スクリーンショット（スマホ・2〜8枚）

実機（Androidスマホ）で次の画面を撮る。

1. 使い方の選択画面（ひとり／家族）
2. ひとりモードのホーム（目標と連続日数）
3. けいそく（ストップウォッチ／タイマー）
4. 終了時の「がんばったことメモ」
5. きろく（日別の履歴）
6. 家族モードの保護者ダッシュボード

## 「アプリのコンテンツ」で答える内容

| 項目 | 回答 |
|---|---|
| プライバシーポリシー | 公開したURLを入力（`store/privacy-policy.md` の内容） |
| 広告 | 広告を含まない |
| アプリのアクセス | 制限なし（ログイン不要。会員登録は任意） |
| データセーフティ（※1.1.0以降。1.0.0は「収集なし」のまま） | 収集するデータ：**個人情報＞メールアドレス**（アカウント管理）、**アプリのアクティビティ／その他のアプリ内コンテンツ**（バックアップした学習記録・名前）、**写真**（アイコンに選んだ写真がバックアップに含まれる場合）。いずれも「任意」（会員登録した人のみ）、第三者への共有：**なし**（Firebase/Googleは処理委託のため「共有」に当たらない）、転送時の暗号化：**あり**、データの削除をリクエストできる：**はい**（アプリ内「設定→アカウント→アカウントを削除」＋メール連絡） |
| データ削除（アカウント） | アプリ内の削除手順を説明し、削除用のURLにはプライバシーポリシーのページを入力 |
| データセーフティ（補足） | 会員登録しない場合は、端末内のみ。登録した場合のみ、メールと学習記録をFirebase（Google）に保存 |
| 対象年齢 | **13歳未満を含める**（5〜8歳は外し、9〜12歳・13歳以上を選ぶ）。家族モードでこどもが使う画面があるため、実態に合わせて申告する（13歳以上だけで申告すると、あとで食い違いを指摘されるリスクがある）。広告・解析SDKはなし。ただし1.1.0で任意の会員登録（メール）を追加したため、ファミリー向けポリシー上は「保護者向けの登録」であることを説明に明記し、こども向けの画面からは登録に誘導しない（現状、登録は保護者の設定画面とひとり用の設定にある） |
| ファミリー向けの追加項目 | 「広告を含まない」「プライバシーポリシーあり」を回答。「教育」カテゴリで申請 |
| コンテンツのレーティング | 教育アプリ。暴力・性的表現・課金・ユーザー間のやりとり：すべてなし |
| ニュースアプリ／政府アプリ／金融機能／健康アプリ | いずれも「いいえ」 |

## 公開までの流れ

1. Play Console でアプリを新規作成（アプリ名・言語：日本語・アプリ／無料）
2. 上記「アプリのコンテンツ」をすべて回答
3. ストアの掲載情報（このファイルの文面・画像）を入力
4. 内部テストまたはクローズドテストに AAB をアップロード
5. 新しい個人アカウントの場合、製品版の前にクローズドテスト（12人×14日）が必要。
   すでに別アプリで条件を満たしていれば、Play Console の表示に従う
6. 製品版を申請 → 審査（数日）
