# まなびチーム 次のアップデートでやること（本人の要望 2026-11-16）

## 1. タイマー終了のお知らせ（本人要望）
終わったことに気づかないので、終了時に知らせる。うるさいアラーム音にはしない。

- 既定は **バイブのみ**（ブブッと短く）
- 設定で選べるようにする：
  - 鳴り方：「バイブのみ」／「バイブ＋やわらかい音」（ポポン・ピポン程度。ピピピピのアラーム音は使わない）
  - お知らせの方法（2択）：「アプリ内だけ（画面を開いているとき）」／「通知でも知らせる」（画面を閉じていても届く）
- 対象：タイマー（親・子・ひとりモード）。ストップウォッチは終わりがないので対象外（必要なら相談）
- 実装メモ：expo-haptics（バイブ）、expo-av か expo-audio（短い音）、expo-notifications（既に導入済み・終了時刻に予約通知）
- ※ iPhone のマナーモード中は音が鳴らない／通知はOS設定に従う、をヘルプに書く

## 2. はじめ方のチュートリアルを足す（2026-11-16 確認で分かった不足）
今のチュートリアル（1.2.0・ビルド18に入っている）は「保護者用5ページ」「こども用5ページ」だけ。

- 最初の「ひとりで使う／家族で使う」選択の説明：なし
- 家族で使うときの登録の流れ（保護者→こどもを追加）：説明が薄い
- **共有コードで家族をつなぐ機能はアプリに存在しない**（家族は1台の端末内で使う作り）。
  別々のスマホで親子をつなぎたいなら、新機能として設計が必要（Firebase で家族コード→参加）。→ 下の3で本人が「作る」と決定。

## 3. 家族コードで複数のスマホをつなぐ（本人決定 2026-11-16）
今の「1台で親子を切り替える」形は残し、**別のパターンとして追加**する。

使い方は3つになる：
1. ひとりで使う
2. 家族で使う（1台）… 今のまま
3. 家族で使う（スマホを分ける）… 新しく作る

3の流れ：
- 保護者A（最初の親）のスマホ：家族を作る → **家族コード**（例：6けた）が出る
- 保護者B（もう1人の親）のスマホ：「保護者として参加」→ コードを入れる
- こどものスマホ：「こどもとして参加」→ コードを入れる → 自分の名前を選ぶ
- 親のスマホ：こどもの勉強時間・タスクの進み具合を見られる、タスクを出せる
- こどものスマホ：タイマー・タスクのチェック。結果は親のスマホに反映される

置き場所：Firebase プロジェクト manabi-team（Sparkプラン・無料）の Realtime Database。
families/{familyId}（メンバー・タスク・記録）、コードは期限つき・使い回し防止。
ログインは匿名ログイン（Firebaseで有効化済み）で始められるようにし、会員登録なしでも使える。
こどものデータを端末の外に置くことになるため、プライバシーポリシー・ASCのアプリのプライバシー・Playのデータセーフティの更新が必要。
チュートリアルは「1台」「スマホを分ける」の両方に用意する。
